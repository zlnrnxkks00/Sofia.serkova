# София Серкова

Статический сайт: HTML, CSS и JavaScript. Сервер, база данных, внешняя загрузка шрифтов и ключи API не требуются. Существующий дизайн сохранён.

## Структура

- `dist/` - редактируемые исходники сайта и локальные изображения, шрифты, иконки.
- `scripts/` - проверка ресурсов и подготовка публикации.
- `tests/` - автономные проверки поведения и адаптивных правил.
- `build/` - готовый сайт, создаваемый сборкой; не редактировать и не добавлять в Git.
- `vercel.json` - настройки Vercel и защитные HTTP-заголовки.
- `.github/workflows/check.yml` - автоматическая проверка каждого push и pull request.
- `docs/DEPLOY.md` - публикация, домен и откат.
- `docs/AUDIT.md` - результаты и ограничения проверки.

## Проверка

Нужен Node.js 24 LTS, не ниже 24.8. Используется npm и зафиксированный `package-lock.json`.

```sh
npm ci --include=dev
npm run check
npm test
npm run build
```

`npm run build` сначала выполняет проверки и тесты. Сборка не меняет `dist/`: обновляет версии CSS/JS, формирует метаданные для действующего домена, `robots.txt` и sitemap в `build/`. Неиспользуемые старые фотографии в публикацию не копируются; исходные файлы остаются на месте. Лицензии библиотек и шрифтов сохраняются.

Локальная сборка без адреса сайта закрыта от индексации. Для production вне Vercel:

```sh
SITE_URL=https://your-domain.example npm run build
```

`SITE_URL` - публичный HTTPS-адрес без пути. Это не секрет. Скрипт получает его из окружения; файл `.env.example` является примером, `.env` автоматически не загружается.

## Vercel

Импортировать закрытый GitHub-репозиторий в Vercel. Корень проекта - корень этого репозитория. Framework Preset: **Other**, Node.js: **24.x**, Output Directory: **build**. Команды уже заданы в `vercel.json`.

Production Branch: `main`. Остальные ветки используются для предпросмотра. Для собственного домена установить `SITE_URL` в окружении **Production** и пересобрать сайт. Без него сборка использует системный production-адрес Vercel. Предпросмотры получают `noindex` и закрытый `robots.txt` независимо от адреса.

Закрытый репозиторий не делает опубликованный сайт закрытым. Доступ к preview настраивается отдельно в Vercel Deployment Protection.

Vercel Hobby предназначен для личных некоммерческих проектов. Для коммерческого сайта услуг нужно выбрать подходящий план, не активируя платные услуги автоматически. См. [правила Vercel](https://vercel.com/docs/plans/hobby).

## Важное

Внешние обращения посетителя: Яндекс Карты и переходы в мессенджеры. Аналитика, cookies-приложения и формы сбора данных не добавлялись. Перед публичным запуском необходимо подтвердить актуальность контактных данных, право публикации фото и разрешение на публикацию отзывов с персональными данными.

Автоматические проверки не заменяют визуальную проверку настоящего развёрнутого сайта на телефоне, планшете и ПК.
