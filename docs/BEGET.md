# Публикация React-сборки на Beget Blog

## Что Размещается

На сервер загружается только содержимое `build/`: готовый HTML, каталог `assets`, `robots.txt` и production sitemap. Node.js нужен локально или в GitHub Actions для сборки, но не на самом Beget. База данных, WordPress и постоянно работающий процесс Vite не требуются.

Рабочая версия в ветке `backup/current-static` и папке `dist/` остаётся резервной. До визуальной приёмки не заменять существующий публичный сайт автоматически.

## Сборка

Использовать Node.js 24 LTS не ниже 24.15 и зафиксированный lockfile:

```sh
npm ci --include=dev
SITE_URL=https://your-domain.example npm run build
```

Заменить адрес на реальный собственный HTTPS-домен без пути, параметров и якоря. `SITE_URL` задаётся именно переменной окружения; простой файл `.env` этот скрипт автоматически не загружает. Не публиковать локальную сборку без домена как production: она специально закрыта от индексации.

## Загрузка

1. В Beget Blog создать сайт или выбрать существующий, проверить привязанный домен и точный путь к `public_html`.
2. Сохранить резервную копию существующего содержимого вне публичной папки, включая заглушку и серверные настройки. Не удалять неизвестные файлы и `.well-known` без проверки.
3. Через SFTP или авторизованный файловый менеджер загрузить **содержимое `build/` прямо в `public_html`**. Не создавать вложенность `public_html/build/index.html`.
4. Не загружать `.git`, `.ssr`, `.vite-public`, `node_modules`, `src`, README, тесты, настройки окружения или SSH-ключи.
5. Выпустить Let's Encrypt в панели Beget. После работоспособного HTTPS включить редирект с HTTP на HTTPS в настройках сайта. `vercel.json` на Beget не исполняется; серверные заголовки и кеширование при необходимости настраиваются отдельно средствами хостинга.
6. Проверить конечный HTTPS-адрес, canonical, Open Graph, JSON-LD, `/robots.txt`, `/sitemap.xml` и доступность файлов из `assets`.

Пошаговая справка: [сайты](https://beget.com/ru/kb/manual/sajty), [доступ к файлам](https://beget.com/ru/kb/manual/ftp), [HTTPS](https://beget.com/ru/kb/how-to/sites/podklyuchenie-ssl-k-sajtu).

## Приёмка

На ПК, планшете и телефоне проверить визуальное совпадение со старым сайтом, нижнюю привязку портретов, мобильное меню, все сцены подхода, историю, услуги, отзывы, карточки контактов, внешнюю карту и отсутствие добавленной внутренней прокрутки. Дополнительно проверить клавиатуру, Escape, повторный выбор пункта меню и системное уменьшение движения. Проверить отсутствие 404, ошибок гидратации и ошибок JavaScript.

Публикация из этой ветки не выполняется автоматически. Автоматизацию GitHub Actions -> Beget можно подключить отдельно после настройки ограниченного доступа по SSH и проверки правильного каталога. Основной пароль аккаунта и закрытые ключи в репозиторий и чат не помещать.
