# Проверка перед публикацией

Дата: 21 октября 2026 года.

## Проверено

- Структура одностраничного сайта: hero, опыт, история, подход, аудитории, ручной массаж, услуги, отзывы, принцип работы, вопросы, контакты и footer.
- Валидность HTML/CSS, синтаксис JavaScript, 31 идентификатор, внутренние ссылки, ARIA-связи и безопасные ссылки в новых вкладках.
- Наличие 44 используемых локальных ресурсов, чтение 25 растровых изображений и размеры изображений в разметке.
- 17 автономных наборов тестов: меню, услуги, отзывы, история и гонки декодирования изображений, переключение сцен, счётчики, анимация canvas, адаптивные правила, размеры портретов, шрифты, SEO и публикационный пакет.
- 12 808 проверок ширины надписей hero по метрикам Onest для ширин 320-1920px; дополнительно длинные заголовки и компактные элементы. Это расчёты, не скриншоты браузера.
- Чистая установка зависимостей и полная сборка на Node.js v24.22.0. Зафиксирован lockfile. На момент проверки `npm audit` не сообщил известных уязвимостей в установленных зависимостях.
- Настроенные поля `vercel.json` сверены с действующей официальной JSON-схемой Vercel.
- Production/preview-сборки: canonical, Open Graph, JSON-LD, robots и sitemap; предпросмотры закрыты от индексации.
- Содержимое `body` в готовом HTML соответствует исходнику. Опубликованные изображения, шрифты, CSS и JS побайтово совпадают с исходниками.
- Служебные каталоги, секреты окружения и зависимости исключены из Git. В публикации нет README, внутренних настроек и старых неиспользуемых фотографий. Исходные материалы не удалены.
- Проверка исходников по распространённым сигнатурам ключей и токенов не выявила действующих секретов. Такая проверка не гарантирует отсутствие любых возможных секретов.

## Исправлено

- Убраны ссылки на неиспользуемый прежний хостинг из метаданных. Адрес публикации теперь формируется при сборке.
- Исправлена повторная навигация из мобильного меню на уже выбранный якорь: страница действительно возвращается к секции.
- Добавлен корректный исходный ресурс и размеры картинки в модальном просмотрщике отзывов.
- Добавлены воспроизводимая сборка, автономные тесты, GitHub CI, настройки Vercel, защитные заголовки и инструкции запуска/отката.
- Исключён устаревший параметр Vercel `public`, который больше не поддерживается.

Дизайн, адаптивные отступы, порядок секций, тексты услуг, цены и изображения не перерабатывались.

## Ещё Не Проверено

Живая визуальная проверка через браузер в этой сессии недоступна. Новые скриншоты и Lighthouse не выполнялись; проверки исходников и тестовые модели DOM не подтверждают фактическую геометрию страницы. До запуска нужно пройти список приёмки из `DEPLOY.md` на развёрнутом preview.

Удалённый GitHub-репозиторий, push, выполнение CI в GitHub и фактический деплой требуют подключения аккаунтов. Локальная успешная сборка не означает, что сайт уже опубликован. Собственный домен пока не задан.

Право публикации фото/отзывов, корректность профессиональных утверждений и актуальность контактных данных должны быть подтверждены владельцем. Автоматические проверки их не подтверждают. Отдельно проверить персональные данные на скриншотах отзывов перед открытой публикацией.
